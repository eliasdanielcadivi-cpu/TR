## 🎯 ¿PARA QUÉ SIRVE?
Es la herramienta principal para escribir código. Se asegura de que no escribamos a lo loco, sino siguiendo un plan por fases.

## 🛤️ FLUJO DE TRABAJO (PASO A PASO)
1. **INVESTIGAR:** Primero entiende el "para qué" antes de tocar una sola línea de código.
2. **PLANEAR (TODO):** Crea un archivo en `docs/TODO/` con las fases y metas.
3. **EJECUTAR:** Escribe el código en módulos pequeños (máximo 3 funciones).
4. **VALIDAR:** Usa `git diff` para mostrarte exactamente qué cambió.
5. **SINCRONIZAR:** Solo cuando una fase termina, actualiza el `LEEME.md`.

## ✅ GARANTÍA
Que el código esté probado antes de que la documentación diga que está listo.
