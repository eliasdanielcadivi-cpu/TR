## 🎯 ¿PARA QUÉ SIRVE?
Para crear automáticamente toda la estructura de carpetas de un nuevo proyecto siguiendo las reglas de ARES-TRON (Kernel V1.1).

## 🛤️ FLUJO DE TRABAJO (PASO A PASO)
1. **REVISAR:** Se asegura de que no estemos en un proyecto ya existente.
2. **CREAR CARPETAS (NÚCLEO):**
   - Crea `src/` para el corazón del programa.
   - Crea `modules/` para las funciones sueltas.
   - Crea `docs/TODO/` para los planes.
   - Crea `bin/`, `config/`, `db/`, `scripts/`, `tests/` y `papelera/`.
3. **CREAR CARPETAS (IA):** Si es un proyecto inteligente, crea `AGENTES/` y `herramientas/`.
4. **CREAR EL LEEME.md:** Crea el contrato de verdad inicial.

## ✅ GARANTÍA
Asegura que todos tus proyectos tengan el mismo orden paranoico.
