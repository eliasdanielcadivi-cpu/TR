# 🟢 HABILIDAD: METACOGNICIÓN (SYS-CONFIG)
# ESTADO: ON (Activa)
# DISPARADORES: ["configurar sistema", "editar memoria", "metacognicion"]

## 🎯 ¿PARA QUÉ SIRVE?
Es el escudo del sistema. Se encarga de modificar los archivos más delicados (el Kernel, la memoria, los routers) de forma segura.

## 🛤️ FLUJO DE TRABAJO (PASO A PASO)
1. **IDENTIFICAR:** Sabe qué parte del núcleo vamos a tocar.
2. **RESPALDAR (.bak):** Crea una copia de seguridad antes de editar nada.
3. **PLANEAR:** Escribe un plan de intervención del sistema.
4. **EJECUTAR:** Cambia el código DSL con precisión quirúrgica.
5. **AUDITAR:** Verifica que el sistema siga funcionando después del cambio.

## ✅ GARANTÍA
Que un error de la IA no rompa todo el sistema operativo lógico.
