# 🌌 EL PROTOCOLO DEL TORRENT (ARES-TRON)

Este documento destila la sabiduría táctica para la adquisición soberana de contenido multimedia.

## 🧠 1. LÓGICA DE BÚSQUEDA
- **Jackett es el Oráculo:** Lento pero infalible. Usa timeouts de 180s.
- **Sintaxis Crítica:** `Nombre Serie` + `Espacio` + `Capítulo`. Ej: `Gen V S02E01`.
- **Estrategia "COMPLETE":** Solo si los capítulos están dispersos o se desea la temporada completa en un solo bloque.

## 💎 2. EL ESTÁNDAR DE CALIDAD
- **1080p o Muerte:** La resolución 720p es inaceptable para un Arquitecto.
- **Seeders:** Ordenar siempre por seeders descendente para asegurar salud y velocidad.

## 👤 3. LOS ELEGIDOS (UPLOADERS)
Prioridad absoluta a:
1. **ETHEL:** El estándar de oro para WEB-DL de alta fidelidad.
2. **MEGUSTA:** El maestro del ratio calidad/peso (x265/HEVC).

## 🛠️ 4. RESILIENCIA TÁCTICA
- **Inyectores:** Si `transmission-remote` falla por RPC, usa `aria2c` como backup resiliente.
- **Visibilidad:** Usa `ares gs deploy` para crear pestañas de monitoreo en tiempo real.
- **Distribución:** Levanta un portal web (Flask/Bootstrap) en la carpeta de destino para acceso local.
