# WhatsApp API

Integración con WhatsApp Web para automatización.

## Dependencias

- Node.js >= 18.0.0
- npm

## Instalación

```bash
# Instalar dependencias
npm install

# Para desarrollo
npm run dev
```

## Dependencias principales

- express ^5.1.0
- qrcode-terminal ^0.12.0
- whatsapp-web.js ^1.34.1

## Uso

Consultar la documentación principal del proyecto para la integración con el sistema ARES.

## Scripts disponibles

- `npm test` - Ejecutar pruebas (pendiente de implementación)

## Notas

Esta API permite la interacción automatizada con WhatsApp Web mediante la biblioteca whatsapp-web.js.
