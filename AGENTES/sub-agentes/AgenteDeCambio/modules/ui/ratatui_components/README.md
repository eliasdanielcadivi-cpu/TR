# Ratatui Components

Componentes visuales Ratatui para AgenteDeCambio CLI.

## Dependencias

- Rust toolchain (>= 1.70)
- Cargo

## Instalación

```bash
# Construir la biblioteca
cargo build --release

# El artefacto se genera en target/release/
```

## Uso

Esta biblioteca proporciona componentes de interfaz de usuario para la CLI de AgenteDeCambio.

## Estructura

- `src/` - Código fuente Rust
- `Cargo.toml` - Configuración y dependencias

## Desarrollo

Para desarrollo, usar:

```bash
cargo build
cargo test
```
