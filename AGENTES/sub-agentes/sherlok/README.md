# Sherlock

Agente de investigación y análisis.

## Dependencias

- Python >= 3.8
- uv (recomendado) o pip

## Instalación

```bash
# Usando uv
uv pip install -e .

# Usando pip
pip install -e .
```

## Dependencias principales

- click
- pyyaml
- rich
- requests
- pydantic

## Uso

Consultar la documentación principal del proyecto para el uso de Sherlock.

## Desarrollo

```bash
# Instalar en modo desarrollo
uv pip install -e .

# Ejecutar pruebas (si existen)
python -m pytest
```
