## 🐛 PROBLEMA NO RESUELTO: LLM RESPONDE CON JSON

### Descripción del Problema

**Cuando:** El orquestador detecta necesidad cognitiva y cambia a modo cuestionario.

**El LLM (DeepSeek):** Responde con formato JSON en lugar de:
1. Dejar que la UI de cuestionario (`QuestionContainer.tsx`) se active automáticamente
2. Responder en lenguaje natural conversacional

### Síntoma Actual (INCORRECTO)

```json
{
  "pregunta": "Para estructurar tu proyecto de negocio de IT sin capital inicial, necesito entender primero tu perfil. ¿Cuál de estas opciones describe mejor tu situación actual?",
  "opciones": {
    "A": "Tienes habilidades técnicas sólidas (programación, redes, ciberseguridad, etc.) pero sin experiencia en negocios",
    "B": "Tienes conocimientos básicos de IT y estás dispuesto a aprender rápidamente",
    "C": "Tienes contactos en el sector que podrían ser primeros clientes o socios",
    "D": "Tienes una idea específica de servicio/producto ya definida",
    "E": "Estás completamente en blanco, solo sé que quieres emprender en IT"
  }
}

**DOCUMENTO DE CONCLUSIONES** (actualizado):
- Contexto: Usuario quiere emprender en IT sin capital inicial
- Necesidad primaria: Estrategias de arranque con $0
...
```

### Comportamiento Esperado (CORRECTO)

```
Para estructurar tu proyecto de negocio de IT sin capital inicial, necesito entender 
primero tu perfil. ¿Cuál de estas opciones describe mejor tu situación actual?

- Opción A: Tenés habilidades técnicas sólidas (programación, redes, ciberseguridad) 
  pero sin experiencia en negocios
  
- Opción B: Tenés conocimientos básicos de IT y estás dispuesto a aprender rápidamente
  
- Opción C: Tenés contactos en el sector que podrían ser primeros clientes o socios
  
- Opción D: Tenés una idea específica de servicio/producto ya definida
  
- Opción E: Estás completamente en blanco, solo sé que querés emprender en IT

Elegí la que más se acerque y contame un poco más sobre tu situación.

[El sistema muestra automáticamente la UI de cuestionario con botones para cada opción]
```

### Posibles Causas Raíz (ANÁLISIS)

1. **Temperature muy alto:** El LLM está en modo "creativo" en lugar de "instrucciones"
2. **Prompt contradictorio:** El `system-master-prompt.ts` puede estar enviando señales mixtas
3. **Falta de few-shot examples:** No hay ejemplos de conversaciones exitosas en el prompt
4. **EL LLM NO SABE QUE EXISTE UI:** Piensa que DEBE generar la estructura porque no tiene contexto de que `QuestionContainer.tsx` ya existe y se activa automáticamente
